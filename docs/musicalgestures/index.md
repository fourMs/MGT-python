# Musicalgestures

API reference for the `musicalgestures` package. Each page below is rendered
directly from the source docstrings by
[mkdocstrings](https://mkdocstrings.github.io/), so the reference always
matches the code on the current branch.

The main entry points are [MgVideo](_video.md), [MgAudio](_audio.md),
[Mg360Video](_360video.md), and [MgList](_mglist.md); most other modules
provide the functions these classes call. See also the
[Complete Reference](../MODULES.md) for the same list with one entry per
module.
